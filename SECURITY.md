# Security

Electron uses context isolation, a sandboxed renderer, disabled Node integration, a narrow validated preload bridge, and a restrictive content security policy. Renderer requests reach the main process only through narrow IPC methods. Hands-free mode is off by default and must be explicitly enabled. The main process validates each model action against a fixed allowlist and limits each spoken request to six screen/action steps. It blocks form submission, sending, deletion, purchases, settings changes, and credential entry. Ollama calls are sent to loopback only. Screen images are not stored. No cloud API keys are used. Keep dependencies updated and review them before release.
