# Security

Electron uses context isolation, a sandboxed renderer, disabled Node integration, a narrow preload bridge, and a restrictive content security policy. Renderer requests reach the main process only through narrow IPC methods. Hands-free mode is off by default and must be enabled once. The main process validates model actions and limits each request to 24 navigation steps; the user can stop it at any time. Forms require exact user-provided values and are never submitted. Sending, deletion, purchases, settings changes, and credential entry are blocked. Spoken HTTP/HTTPS site requests open in the system default browser. Ollama calls stay on loopback. Screen images are not stored. Explicit web searches send the spoken query to DuckDuckGo; screen contents are not included. Keep dependencies updated and review them before release.
