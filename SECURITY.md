# Security

Electron uses context isolation, a sandboxed renderer, disabled Node integration, a narrow preload bridge, and a restrictive content security policy. Renderer requests reach the main process only through narrow IPC methods. Hands-free mode is off by default and must be explicitly enabled. The main process validates each model action and limits a request to six navigation steps; forms require exact spoken values and are never submitted. Sending, deletion, purchases, settings changes, and credential entry are blocked. A spoken browser-open command opens the system default browser. Ollama calls stay on loopback. Screen images are not stored. Explicit web searches send the spoken query to DuckDuckGo; screen contents are not included. Keep dependencies updated and review them before release.
