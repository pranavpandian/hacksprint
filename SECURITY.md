# Security

Electron uses context isolation, a sandboxed renderer, disabled Node integration, a narrow validated preload bridge, and a restrictive content security policy. Renderer requests reach the main process only through narrow IPC methods. The main process bounds screen payloads, validates model-proposed actions against a fixed allowlist, and only performs a click, text entry, or limited key press after the user approves it in the UI. Ollama calls are sent to loopback only. Screen images are not stored. No cloud API keys are used. Keep dependencies updated and review them before release.
