On Windows, the BridgeUX installer bundles speech/sign assets and first-run setup installs Ollama plus `qwen3.5:4b`. For a manual source checkout, install Ollama and run `ollama pull qwen3.5:4b`, then start the app with `npm start`. BridgeUX reads active-window controls first and uses the browser extension for the active tab when paired. Explicit everyday actions run without turning on continuous hands-free mode. Forms ask for missing values and submit only when you directly request it. The local model can be wrong, so review important information.
